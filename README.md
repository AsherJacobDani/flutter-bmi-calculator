# 🏋️ BMI Calculator

A Flutter-based BMI (Body Mass Index) calculator with Firebase authentication and BMI history tracking. Compatible with Android devices.

## ✨ Features

- 📧 Email & Password Registration / Login (Firebase Auth)
- 📊 BMI Calculation with detailed results
- 📁 BMI History tracking per user
- 🌙 Light & Dark Mode support
- 👤 User Profile screen
- 📤 Share BMI results

## 🛠 Built With

- [Flutter](https://flutter.dev/) - Cross-platform UI framework
- [Firebase Auth](https://firebase.google.com/docs/auth) - Email/password authentication
- [Firebase Core](https://firebase.google.com/docs/flutter/setup) - Firebase integration
- [Shared Preferences](https://pub.dev/packages/shared_preferences) - Local BMI history storage
- [Share Plus](https://pub.dev/packages/share_plus) - Share BMI results
- [Screenshot](https://pub.dev/packages/screenshot) - Capture result screen

## 🚀 Getting Started

### Prerequisites
- Flutter SDK (^3.12.0)
- Android Studio or VS Code
- Firebase project with Email/Password Auth enabled

### Setup

1. Clone the repo:
   ```bash
   git clone https://github.com/AsherJacobDani/flutter-bmi-calculator.git
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Add your `google-services.json` to `android/app/`

4. Run the app:
   ```bash
   flutter run
   ```
