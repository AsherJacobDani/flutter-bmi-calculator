# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it by opening an issue in the [GitHub repository](https://github.com/AsherJacobDani/flutter-bmi-calculator/issues).

Please include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact

All reports will be reviewed and responded to as quickly as possible.
